# Typescript Take-home Exercise

This is a NodeJS API for the take-home exercise.

## Getting Started

### Requirements

- A modern version of NodeJS.
- We recommend using `pnpm`.

### Installation

Ensure you have a package manager such as `pnpm`. The lockfile provided is for `pnpm` so we recommend using that.

```sh
pnpm i
```

### Running the Application

```sh
pnpm dev
```

This will start the main service on port `8080` and the mock service on port `8888`.
